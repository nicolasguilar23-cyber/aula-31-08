## Codigo em linha e bloco de codigo

O comando git status mostra o estado atual do repositório

O Comando git add . adiciona todos os arquivos modificados à Staging Area.

O Comando git commit -m "Mensagem de Comentario" registra as alterações com uma mensagem.

O Comando git push envia os arquivos para a nuvem

```
git status
git add . 
git commit -m "Mensagem de Comentario"
git push
```
